# SpaceWar

A small **2D space racing / endless-runner game** developed in Unity as a personal experiment in gameplay mechanics.

The project explores the implementation of a simple arcade-style game loop and was also published as a playable build on itch.io.

## Gameplay

The player controls a spacecraft while navigating an endlessly generated space environment.

The project focuses on experimenting with:

* player movement;
* obstacle avoidance;
* continuous gameplay;
* game progression;
* arcade-style game mechanics.

## Technologies

* Unity
* C#

## Play the Game

**[Play the game on itch.io](https://singularityy.itch.io/space-war)**

## Purpose

This project was developed as a personal experiment to practice Unity and C# while building a complete, playable game rather than implementing isolated mechanics.

## What I Learned

* Implementing gameplay mechanics in Unity
* Structuring a small game project
* Building a continuous gameplay loop
* Creating and testing a playable game build
